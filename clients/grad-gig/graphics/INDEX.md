# Grad Gig: motion graphics library

Every motion graphic used in Grad Gig videos, and what Tait thinks of it. The
Editor and Motion Designer use whatever fits (Tait, 2026-10-21) and log each
one here; Tait's feedback teaches which graphics belong in which parts of a
video. Graphic code lives in `editor/src/clients/grad-gig/` (private).

## How a graphic gets in here
1. **Use it.** The Editor (with the Motion Designer) uses whatever graphic fits
   the moment, each with a purpose and real facts only, and logs it under
   **Used, waiting for Tait** (date, video, time, the line, the graphic).
2. **Tait reacts** when he watches the video: keep it, say where it belongs, or
   never again, with his why.
3. **Kept** graphics move to the table below with where they work best;
   rejected ones go to Passed with his reason, so the team learns.
